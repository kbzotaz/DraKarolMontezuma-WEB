# Dra. Karol Montezuma - Web

Sitio web profesional orientado a dermatología estética y terapéutica.

## Sitio
https://drakarolmontezuma.com

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Sobre el proyecto
Desarrollo de una página web enfocada en la presentación profesional y captación de pacientes, priorizando un diseño limpio, moderno y una buena experiencia de usuario.

## Publicación
El sitio se encuentra publicado mediante GitHub Pages, vinculado a dominio personalizado.
